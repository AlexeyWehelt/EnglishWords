# Тренажёр английских слов

Программа показывает и произносит английское слово, ученик отвечает по-русски голосом или письменно. У каждого слова есть рейтинг от 0 до 5: чем лучше ответы, тем реже слово попадается. Когда у всех слов рейтинг 4 и выше, загорается зелёный индикатор.

Открыть: https://alexeywehelt.github.io/EnglishWords/

## Аккаунты

Вход по имени и паролю из 4 цифр, как в лабиринте. Данные хранятся в Firebase Realtime Database проекта CrazyMaze1, в разделе `users`, с приставкой `w_` к имени (например, `users/w_юра`). Так тренажёр работает с текущими правилами базы лабиринта, а его аккаунты не пересекаются с игроками.

Аккаунт «Юра» при создании получает базовый набор из 117 слов. Остальные новые аккаунты создаются пустыми.

Для проверки без сервера добавьте `#local` в конец адреса: аккаунты будут храниться в этом браузере.

## Загрузка слов

Вкладка «Загрузка» пополняет словарь того, кто вошёл: слова через запятую или по строкам (`bank (берег)`, `apple — яблоко`), целый английский текст (устойчивые выражения находятся сами), файлы .txt, .csv, .xlsx, фотографии .jpg/.png (текст распознаётся прямо в браузере через Tesseract.js) и архивы .zip с ними. Перевод новых слов подставляется автоматически через Google Translate (запасной вариант — MyMemory) и правится вручную перед добавлением.

## Примеры и картинки

При неверном ответе показывается фраза с этим словом, её перевод и смешная картинка. Сложность фразы зависит от уровня слова: уровень берётся из списка CEFR-J (A1–A2 — предельно простая фраза, B1–B2 — посложнее, C1–C2 и редкие слова — серьёзное предложение), а для слов не из списка — по частотности (`words-common.txt`). Фразу пишет нейросеть через бесплатный сервис Pollinations (text.pollinations.ai) и сохраняет в базе, картинку рисует image.pollinations.ai. Для 117 слов базового набора фразы встроены.

Список уровней `word-levels.txt` составлен по CEFR-J Wordlist Version 1.5 (Yukio Tono, Tokyo University of Foreign Studies, http://www.cefr-j.org/) и Octanove Vocabulary Profile C1/C2 (Octanove Labs, CC BY-SA 4.0), взяты из https://github.com/openlanguageprofiles/olp-en-cefrj.

## Голосовой ответ

Работает в Chrome, Edge и Safari. При первом нажатии на микрофон браузер спросит разрешение.

Слова с коротким переводом (о, в, и, на…) обычный распознаватель браузера пропускает, поэтому для них работает офлайн-распознаватель Vosk (`vosk.js` — сборка vosk-browser, `vosk-model-small-ru.tar.gz` — модель vosk-model-small-ru-0.22, обе под лицензией Apache 2.0). Ему передаётся список ожидаемых ответов, поэтому одиночные предлоги он слышит уверенно. Модель (около 45 МБ) скачивается один раз и хранится в браузере.
