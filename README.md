# Тренажёр английских слов

Программа показывает и произносит английское слово, ученик отвечает по-русски голосом или письменно. У каждого слова есть рейтинг от 0 до 5: чем лучше ответы, тем реже слово попадается. Когда у всех слов рейтинг 4 и выше, загорается зелёный индикатор.

Открыть: https://alexeywehelt.github.io/EnglishWords/

## Аккаунты

Вход по имени и паролю из 4 цифр, как в лабиринте. Данные хранятся в Firebase Realtime Database проекта CrazyMaze1, в разделе `users`, с приставкой `w_` к имени (например, `users/w_юра`). Так тренажёр работает с текущими правилами базы лабиринта, а его аккаунты не пересекаются с игроками.

Аккаунт «Юра» при создании получает базовый набор из 117 слов. Остальные новые аккаунты создаются пустыми.

Для проверки без сервера добавьте `#local` в конец адреса: аккаунты будут храниться в этом браузере.

## Голосовой ответ

Работает в Chrome, Edge и Safari. При первом нажатии на микрофон браузер спросит разрешение.
