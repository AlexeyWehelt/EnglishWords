# Контекст проекта «Тренажёр английских слов»

Сохранено 29.10.2026, текущая версия страницы — **16** (подпись под формой входа).
Сайт: https://alexeywehelt.github.io/EnglishWords/ · репозиторий AlexeyWehelt/EnglishWords (ветка `main`, GitHub Pages из корня).

## Требования заказчика (в порядке поступления)

1. Набор английских слов → показ по одному в случайном порядке, слово пишется и произносится. Ученик отвечает по-русски голосом или текстом. Программа говорит «правильно/неправильно» и показывает все основные значения. Кнопка «Далее».
2. Слова вводятся через запятую или целым текстом, дубли не создаются. Конкретный смысл — в скобках: `bank (берег)`. Устойчивые выражения (`a lot of`) распознаются в тексте.
3. Рейтинг слова по ответам: хорошо отвечаемые слова встречаются реже. Когда все слова выучены — зелёный индикатор.
4. Базовый набор — xlsx-список из 117 простых слов (встроен в `index.html`, константа `BASE`).
5. Поток: «Начать» → слово, через 0,5 с произносится → микрофон (распознанный текст в поле, проверка сразу) или ввод в поле + Enter / «Ввод». Кнопку «ручка» убрали. Результат → «Далее».
6. Многопользовательский режим с входом как в лабиринте Maze1 (имя + пароль из 4 цифр, Firebase CrazyMaze1). Аккаунт «Юра» получил базовые слова с нулевой статистикой; новые аккаунты пустые. Позже «папа» тоже получает базовый набор (`SEED_ACCOUNTS`).
7. Меню: «Тренировка», «Усваиваемость», «Занятия», «Загрузка».
8. При ошибке — простая фраза-пример со словом, озвучивается, ниже перевод.
9. Кнопка «Не знаю». Двойное N — режим без статистики (надпись над карточкой). Двойное R на «Усваиваемости» — редактирование значений и удаление слов.
10. Рейтинг от 0 (нейтральное) в плюс и минус, быстрые ответы повышают сильнее, медленные почти не влияют.
11. «Статистика занятий»: время начала и количество отработанных слов.
12. Слова с рейтингом выше +5 уходят в архив: не показываются и не участвуют в статистике (возврат — на «Усваиваемости», фильтр «Архив»).
13. «Загрузка»: слова из текста, файлов (.txt/.csv/.xlsx), фото (.jpg/.png, распознавание текста) и ZIP с фото. Брать только адекватные частые слова, без терминов, аббревиатур, устаревших значений.
14. Предлоги голосом должны распознаваться.
15. Фраза-пример по сложности зависит от уровня слова (pen/cat/предлоги — предельно просто; agriculture — посложнее; ambidextrous — серьёзное предложение). К фразе — иллюстрация; можно взять готовую картинку и составить фразу по ней.
17. Окно при ошибке: только правильный ответ, фраза по-английски и по-русски (+ картинка). Фразы читаются вслух: сначала английская, потом русская; читаемая выделена жирным. «Далее» появляется только после чтения.
16. Эксперимент «папа»: замерить время ответа на хорошо знакомые слова и давать таким ответам больший балл.

## Как устроено сейчас (версия 15)

**Файлы:** `index.html` (всё приложение), `firebase-config.js` (проект crazymaze1-fd7a0, Realtime Database asia-southeast1), `words-common.txt` (~10 400 частых базовых форм по частотности, Google 20k + hunspell), `word-levels.txt` (уровни CEFR-J A1–C2), `vosk.js` (сборка vosk-browser 0.0.8 из примеров репозитория ccoreilly/vosk-browser), `vosk-model-small-ru.tar.gz` (vosk-model-small-ru-0.22, 46 МБ, взята из репозитория Priler/jarvis), `README.md`.

**Аккаунты:** `users/w_<имя>` в базе лабиринта (обходной путь: правила Firebase не правятся — консоль требует MFA). Хэш пароля SHA-256 от `ключ:код`, как в лабиринте. Без сервера: адрес с `#local` (localStorage).
Данные аккаунта: `words/<ключ>` {en, ru[], r, seen, ok, t, last, a(архив, время), ex{en, ru, lvl, src, img{thumb,title,by,lic,link,src}, v:2}}, `sessions/<id>` {start, end, n, ok}, `log/<push>` — журнал ответов.

**Рейтинг:** шкала −5…+5, усвоено с +3, выше +5 — архив. Неверно / «Не знаю» −1. Верно — по времени от показа слова до начала ответа (голос: начало речи; текст: первая буква):
- до базового + 0,6 с → +1,5 («быстрый ответ»);
- до базового + 2 с → +1;
- далее линейно до +0,1 на базовом + 12 с.
Базовое время: голос 2,2 с, текст 2,6 с; после 15 верных ответов на слова с r0 ≥ 2 — медиана ученика, ограниченная 1,6–3 с.
Выбор слова: вес 2^((3 − r)/1,5), последние 4 слова не повторяются.

**Проверка ответа:** нормализация (ё→е), допуск опечатки в 1 букву только для слов от 6 букв (петь ≠ пить), общие основы, приставочные пары (поставить = ставить), видовые пары глаголов (отправить/отправлять), короткие слова (о, и, в) с исправлением типичных огрехов распознавания, проверка каждого слова фразы, все варианты распознавания.

**Голос:** обычные слова — Web Speech API (ru-RU, интерим-результаты, автоостановка, 0,8 с тишины → ответ, максимум 8 с). Слова с коротким переводом (≤ 3 буквы) — Vosk в браузере с грамматикой из всех значений словаря + частых коротких слов + `[unk]`. Модель грузится по абсолютному адресу (относительный внутри воркера не работал), кешируется в IndexedDB, предзагрузка при «Начать», пока грузится — обычное распознавание. Начало речи для Vosk — по уровню звука.

**Примеры и картинки:** уровень слова — CEFR-J (A1–A2 → 1, B1–B2 → 2, C1–C2 → 3), не из списка — по частотности/длине. Картинка из Wikimedia Commons (без ключа; Openverse отказались — 5 анонимных поисков в час). Поисковые слова: для 117 базовых — вручную (`IMGQ_SRC`), для остальных — от нейросети. Затем нейросеть Pollinations (text.pollinations.ai, модель openai, POST /openai с image_url) смотрит на картинку и пишет фразу по уровню + перевод. Сохраняется в `ex` (v:2). Запросы последовательно, тайм-ауты 15–30 с, предзагрузка не больше 2 в очереди. Без нейросети — встроенная фраза (`EXAMPLES_SRC`) + картинка.

**Загрузка:** разбор списков, пар «word — перевод», скобок, текста (выражения из `PHRASES_SRC`, лемматизация, неправильные глаголы); из текста и фото берутся только слова из `words-common.txt`, остальное — в «Пропущено». OCR — Tesseract.js 5 (eng+rus): подбор поворота по 4 вариантам, чтение как страницы и как разрозненного текста (облачка), только уверенные слова. Автоперевод — Google Translate (gtx), запасной MyMemory; берутся только основные значения. Предпросмотр с галочками и правкой.

**Занятия:** таблица занятий, таблица «Скорость ответа» (медианы) и кнопка «Скопировать журнал ответов» (TSV: ts, en, ok, m, short, lvl, t, saidEnd, said, mic, done, r0, seen, p, ans; времена в мс от показа слова).

## Результаты эксперимента «папа» (27.10.2026, 48 верных ответов голосом)

- Начало ответа: медиана 2,2 с, p90 2,7 с, максимум 3,3 с; короткие слова ~2,0 с; повтор не быстрее первого показа.
- Из них механика: произношение слова начинается в 0,7 с, микрофон нажат в 1,4 с, речь начинается через ~0,8 с после нажатия; ответ засчитан в 3,3 с.
- Текстом намного медленнее (12–19 с до результата).
- Ошибки проверки, найденные в журнале и исправленные в версии 15: set → «поставить» (было неверно), drink → «петь» (было верно).
- Сомнительные распознавания: in → «за», complete → «поставить».

## Ограничения и открытые вопросы

- Из среды Claude недоступны Firebase, GitHub Pages, Pollinations, Wikimedia, Vosk CDN — проверка только на подставных данных; живую проверку делает пользователь.
- Правила Firebase не меняются, пока не включена двухэтапная проверка Google; потом можно перенести данные тренажёра в отдельный раздел со своими правилами.
- На телефоне не работают NN и RR (нет событий клавиш); предлагалось включение долгим нажатием.
- Firefox не поддерживает голосовой ввод.

## Сеть на компьютере ученика

На компьютере стоит системный прокси 127.0.0.1:80 с исключениями (открыты только `*.github.io` и сайты школы). Для работы тренажёра в исключения нужно добавить: `*.firebasedatabase.app;*.firebaseio.com;www.gstatic.com` (вход), `www.google.com` (голос в Chrome), `text.pollinations.ai;commons.wikimedia.org;upload.wikimedia.org` (примеры и картинки), `*.googleapis.com;cdn.jsdelivr.net;cdnjs.cloudflare.com;tessdata.projectnaptha.com;api.mymemory.translated.net` (загрузка). Предложено (не сделано): все слова распознавать через Vosk и работать с базой через REST без библиотеки Firebase, чтобы обойтись github.io и базой.
